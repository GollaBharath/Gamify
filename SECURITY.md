# Security Policy

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

We take the security of our application seriously. If you find any vulnerability, please report it privately.

**Please do NOT open public issues for security vulnerabilities.**

Instead, please email us directly with details about the security flaw:
- Email: security@example.com
- Expected response SLA: within 48 hours.

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Impact details.
